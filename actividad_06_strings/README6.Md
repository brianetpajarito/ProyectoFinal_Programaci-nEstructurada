# Actividad: Strings
## Descripción
Programas que hacen uso y solicitan cadena de caracteres, además de uso de funciones para cadenas

## Temas aplicados
- scanf
- fgets
- Arreglos
- Condicionales
- Operadores lógicos
- Ciclo for
- If-else anidado
- strlen
- stcpy
- stcat
- strcmp

## Compilación
gcc String.c -o String.exe
## Ejecución
.\String.exe
